操作、角度约定与物理假设

COMPTON REAL-SPACE CONE · REFERENCE NOTES

1. 这个交互在展示什么

场景中有一个公共原点 O、以 O 为球心、半径 R 的天空方向球，以及固定源方向 S。红色的 真实 event cone 顶点在 O；它的轴是反投影轴 a；与方向球相交得到红色 event circle。无论 β 怎样旋转，event circle 都经过固定的源标记 S。

蓝色标记 A 是反投影轴 a 在方向球上的端点 O + R a，也是 event circle 的球面角中心。蓝色历史线记录的是 A 的轨迹，不是 event circle 所在平面的欧氏圆心 B。

文字含义边界： 本页把 O 当作当前示例事件的第一次相互作用位置；比较不同事件时，O 只是把不同方向向量平移到一起后的公共方向原点。真实观测中，不同光子的第一次相互作用位置并不相同。event circle 是一次事件允许的候选源方向集合，不是实际发射光子的圆环。旋转动画表示生成一族“同源方向、同 φ、不同散射方位”的可能事件，不表示一个已经测量完成的光子事件在探测器中旋转。

2. 本页实际采用的角度约定

使用右手物理坐标系 x、y、z。χ 从 −z 方向量起，范围 0°–180°；ψ 是 xy 平面方位角，从 +y 朝 +x 增大，范围 0°–360°。所有计算内部使用弧度，界面显示角度。

d(χ, ψ) = (sinχ sinψ, sinχ cosψ, −cosχ)

在 χ = 0° 或 180° 的极点，ψ 没有唯一物理定义；界面显示“未定义（极点）”，不会让数值抖动或产生 NaN。参考图没有完全确定 ψ 的零方位，因此“从 +y 朝 +x”是本实现明确采用的选择，而不是声称所有 Compton 文献都采用它。

本页公式使用离线 KaTeX（LaTeX 排版）渲染，所需字体已内嵌在单文件中，不加载网络资源。

3. 源方向、入射方向、散射方向与反投影轴

s₀ 是从 O 指向源的固定单位向量；S = O + R s₀。入射光子传播方向与源方向相反：nin = −s₀。散射后光子的单位传播方向记为 k；朝天空的反投影轴 a = −k。

cosφ = n_in · k = (−s₀) · k = s₀ · a

χ、ψ 描述的是 k，不是 a。

4. 真实 event cone 的旋转构造

对固定源方向 s₀，取与 s₀ 垂直的正交单位基底 b₁、b₂，满足 b₂ = s₀ × b₁。β 是绕固定源方向 O—S 的额外旋转参数，不是 ψ。event cone 的反投影轴为：

a(φ, β) = cosφ · s₀ + sinφ · ( b₁ cosβ + b₂ sinβ )

event circle 上的候选源方向 s(t) 满足 |s| = 1、s·a = cosφ。为了在 φ→0° 或 180° 时不除以接近零的 sinφ，构造使用无除法分支：

u = sinφ · s₀ − cosφ · (b₁ cosβ + b₂ sinβ)

⇒ event circle 精确经过 S

真实 event cone 是从 O 沿这些方向延伸 0 ≤ ρ ≤ R 的母线集合，不是固定 45° 的普通 ConeGeometry。红色锥面是半透明的；φ = 90° 时它退化为过 O 的平面盘，而不是有有限高度的普通圆锥。

5. A、B 与轨迹的几何事实

A = O + R a, B = O + R cosφ · a, A ≠ B

（天空球上的球面角中心，蓝点）  ·  （event circle 所在平面内的欧氏圆心，通常位于球内）

A 一般 ≠ B

固定 φ 时，A 的完整轨迹是一个平面小圆：平面垂直于 s₀，几何圆心为 O + R cosφ · s₀，欧氏半径为 R sinφ；以 S 为球面角中心时，角半径是 φ。不要把 R sinφ 标成 φ，也不要用弦长冒充球面弧长。沿球面从 S 到 A 的大圆弧中心角为 φ，弧长为 Rφ（φ 用弧度）。

“理论小圆”开关只显示当前 φ 的完整理论轨道，使用很淡的虚线，与已经扫过的蓝色历史轨迹明确区分，且可关闭。B 标记默认隐藏，打开时显示“平面圆心 B”。

6. 历史轨迹规则

  • 只显示已经扫过的部分；初始不会预画一整圈实线。
  • 轨迹按角度采样，间隔 0.25°，不是只按动画帧率采样；快速拖动 β 时插值补全区间。
  • 每段记录自己的 φ、扫过的累计 β、对应单位方向向量和样式。渲染时绝不把旧点重新套用成最新 φ。
  • 改变 φ 时先闭合旧段，再开启新段；绝不在不同 φ 的点之间画连线。只改 φ 不会生成新的蓝线。
  • 视角变化、缩放、暂停/继续、显示开关、重置视角都不删除历史。只有“清空轨迹”删除历史，而且不会重置 φ、β 或相机。
  • β 内部保留未取模的累计角度，显示时回绕到 0°–360°。β 的绝对数值输入按显示旧值→新值的数值差录制，不做“最短角路径”修正，所以 0°→360° 会留下完整一圈。手动调整数值会暂停自动旋转。

7. Compton 能量关系

给定入射光子能量 E = 1000 keV 的紧凑示例：

E′ = E / [1 + (E/mₑc²)(1 − cosφ)], Tₑ = E − E′

若通过第一次散射的电子能量沉积 Eₑ 和散射后光子的完全吸收能量 E_γ 反算 φ，可使用：

cosφ = 1 − mₑc²(1/E_γ − 1/(Eₑ + E_γ))

本页同时显示当前 E′ 和 Tₑ。这里的旋转是按 β 均匀生成几何，不是真实探测计数分布；实际事件概率还需 Klein–Nishina 截面、探测器几何、接受度与筛选条件，本版本不模拟这些概率。

8. 操作与观察方式

轨道观察（默认）

  • 左键拖动：绕 O 旋转观察视角
  • 右键或 Shift + 拖动：平移观察中心
  • 滚轮：缩放
  • 可以从上方、侧方、下方观察

自由观察

  • 明确点击“自由观察”进入，浏览器会请求 Pointer Lock
  • 移动鼠标：改变朝向
  • W/A/S/D：水平移动；Q/E：下降/上升
  • Shift：加速；Esc：退出并回到轨道视角
  • 若浏览器未授予 Pointer Lock，可直接拖动画面转向

相机操作不会改变物理参数。 “绕源方向旋转 event cone”与“移动摄像机观察场景”是两种独立操作；旋转视角不会被当成 β。

投影字号： 左侧“投影字号”可在标准 / 大字 / 特大之间切换。1920×1080 建议“大字”；较低分辨率或较远观看距离建议“特大”。长操作说明集中在本弹层，不在主界面常驻。

角度辅助默认隐藏，可在左侧打开 φ、χ 和 ψ 辅助弧。

9. 简化、范围与限制

  • 理想化：遥远点源；入射光子在探测器尺度上近似平行；初始电子静止；使用自由电子 Compton 关系。
  • 不考虑测量误差、Doppler broadening、背景和探测器接受度；展示的是几何上允许的一族事件。
  • O 的双重用途按第 1 节说明：示例事件可视为第一次相互作用位置；不同事件比较时只是公共方向原点。
  • φ 的滑块步长较小但有限；极点附近角度辅助线会退化为不可见或极短，而物理量仍给出有限值。
  • 本版本不实现 Compton data space、球面到平面投影、图像重建或固定 45° 辅助锥。所有位置与角度都按完整双精度计算后再送入渲染。
  • 红色锥面在 φ = 90° 附近是真实几何的平面盘；φ 接近 0° 或 180° 时锥面接近一条射线并可能显得薄。
